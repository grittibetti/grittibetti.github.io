Research/TAKDE

Adaptive estimation

Learning a distribution that will not sit still.

TAKDE turns the familiar sliding-window kernel density estimator into a principled tool for data streams whose underlying distribution changes over time.

Yinsong Wang · Yu Ding · Shahin ShahrampourIEEE TPAMI · 2023

Project 01

The problem

A density estimate is a picture of where data are likely to appear. For a stationary process, accumulating more observations usually sharpens that picture. In a dynamic process—traffic flow, sensor readings, or a moving target—old observations can instead pull the estimate toward a world that no longer exists.

A sliding window is the natural response: retain recent samples and discard older ones. But this replaces one question with another. How wide should the window be, and should every moment inside it count equally?

The idea

We derived an upper bound on the asymptotic mean integrated squared error of a sliding-window kernel density estimator. That analysis reveals how estimation error depends jointly on sample size, bandwidth, and temporal change. TAKDE uses this structure to select a window and assign temporal weights rather than relying on a fixed heuristic.

The estimator adapts its memory to the pace of change.

Why it matters

When the process changes slowly, a longer memory provides more data and a smoother estimate. When it changes quickly, recent observations receive greater influence. Experiments on synthetic and real data showed that this theoretically guided balance can improve predictive likelihood while reducing runtime relative to competing dynamic density estimators.

The broader lesson is that forgetting is not merely a computational convenience. In a changing environment, it is part of the statistical model.
