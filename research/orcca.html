Research/ORCCA

Efficient approximation

Random features chosen for the task.

ORCCA asks a simple question with broad consequences: if we can afford only a limited set of random features, which ones matter most for the learning objective?

Yinsong Wang · Shahin ShahrampourIEEE TNNLS · 2021

Project 02

The problem

Kernel methods can represent nonlinear relationships, but their computation grows quickly with the number of observations. Random features make them scalable by replacing an implicit, high-dimensional kernel representation with a finite collection of explicit features.

The usual approach samples features to approximate the kernel well in general. But a feature that reconstructs the kernel may not be the feature that best serves a particular downstream task.

The idea

Canonical correlation analysis seeks directions in two data views that are maximally correlated. ORCCA derives a scoring rule that measures how useful a candidate random feature is for this objective, then samples features according to that task-specific score.

Approximation should preserve what the task needs—not everything equally.

Why it matters

This reframing gives a principled way to allocate a limited feature budget. The theory shows that the resulting method can outperform the corresponding kernel CCA with a default kernel in expectation, and numerical experiments demonstrate substantial gains over other approximation strategies.

More broadly, ORCCA points toward task-aware randomized computation: efficient learning algorithms that spend their approximation budget on the structure relevant to the decision at hand.

  • MethodTask-specific feature scoring
  • Use casesMulti-view and multimodal learning
