Research/ORCCA

Large-scale · multimodal data

Random features chosen for the task.

If you can afford only a few random features, which ones should you keep? ORCCA picks them by how much they help the learning objective, not by how well they copy the kernel.

Yinsong Wang · Shahin ShahrampourIEEE TNNLS · 2021

Project 05

Two views of the same system

Many engineering systems are observed through more than one lens: vibration sensors and camera images of the same machine, or process signals and quality measurements of the same batch. A natural question is: what do the two views have in common? Canonical correlation analysis (CCA) answers this by finding a projection of each view so that the two projections are as correlated as possible.

Real relationships are rarely linear, so in practice we use kernel CCA, which first maps each view through a rich nonlinear feature space. The catch is cost: exact kernel methods build n×n matrices and scale roughly with the cube of the number of samples. With large-scale data they simply stop being affordable.

What people usually do

The standard fix is random features: replace the kernel with a few hundred explicit random cosine features and run ordinary linear CCA on them. The frequencies are drawn from the kernel's spectral distribution, which is a clever way to approximate the kernel well in general.

But "approximate the kernel well" is not the same goal as "find the correlation well." Many randomly drawn features spend the budget on directions that carry no shared signal between the two views, so you need a lot of them.

Our idea: spend the feature budget on the task

ORCCA (Optimal Randomized CCA) asks a sharper question: if we can afford only a limited number of features, which ones matter most for correlation? We derived a score that measures how useful each candidate random feature is for the CCA objective, then sample features in proportion to that score. Features that help explain the shared structure get picked more often, and useless ones get dropped.

Approximation should preserve what the task needs, not everything equally.

What we found

We showed that this task-aware sampling can outperform kernel CCA with a default kernel, in expectation, and in numerical experiments ORCCA gave substantial gains over other random-feature approximation strategies for the same number of features.
