Research/Scalable & Adaptive Distribution Regression

Large-scale · distributional data

Predicting from whole distributions, fast.

When every input is a bag of measurements, exact kernel methods get expensive and picky about the kernel. RaDR keeps their guarantees at random-feature speed, and A-RaDR adapts the features to the task.

Yinsong Wang · Xiao Liu · Yu DingarXiv preprint · 2026

Project 01

When each input is a whole distribution

In many engineering problems, a single "input" is not a point but a bag of measurements. A manufacturing batch comes with the size distribution of thousands of particles; a patient comes with a cloud of sensor readings; a geographic region comes with many sampled observations. What we want to predict, such as yield, a health outcome, or an average, belongs to the whole bag.

This is distribution regression. The data come from two-stage sampling: first we observe a set of distributions, then only a finite sample of points from each one. So we never see the distributions themselves, only noisy, finite snapshots of them.

What people usually do

The classical approach embeds each distribution in a kernel feature space and runs kernel ridge regression on the embeddings. It works well statistically, but it is expensive: the n×n Gram matrix compares every pair of bags, and each entry compares every pair of points across the two bags. Accuracy also depends heavily on picking the right kernel.

Our idea: random features, with a guarantee

Random features make this cheap. Map each point into D random features, average them within each bag, and you get one fixed-length vector per distribution. Plain linear ridge regression on those vectors then replaces the full kernel machinery. We call this RaDR (Random Feature Distribution Regression).

The natural worry is that we pay for the speed with accuracy. Our analysis splits the excess risk into three sources: sampling the distributions, sampling points within each distribution, and approximating the kernel with random features. We derived conditions on the number of features under which RaDR keeps the same excess-risk order as exact two-stage kernel methods while being far cheaper to compute.

Then we addressed kernel sensitivity. Adaptive RaDR (A-RaDR) allocates random features using scores tied to the downstream learning objective, in the same spirit as ORCCA: spend the feature budget where the prediction task needs it, instead of committing to one fixed kernel.

Kernel-level guarantees at random-feature speed, with features that adapt to the task.

What we found

On synthetic benchmarks and 41 real-world datasets, RaDR cut computation substantially while staying competitive in accuracy, and A-RaDR improved accuracy further while keeping that speed advantage.
